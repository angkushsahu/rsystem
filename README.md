# R-System

![R-System Preview](/rsys-ui.webp)

### Project Description

A lightweight, cross-platform system monitoring CLI built with **Rust**. It provides a real-time overview of system resource utilization, CPU activity, memory consumption, and running processes through a clean, terminal-based interface.

### Core features

- Per-core CPU usage
- Memory monitoring
- Disk monitoring
- Performance graphs
- Process monitoring
- Sortable process table (by CPU and Memory usage)
- Real-time updates

## 🚀 Installation

> **Note:** Make sure that rust is installed in your system, you can install rust from their [official website](https://rust-lang.org/tools/install/).

### Build from source

```bash
git clone https://github.com/angkushsahu/rsystem.git
cd rsystem
cargo build --release
```

The compiled binary will be available at:

```text
target/release/rsys
```

### Install system-wide (Linux)

```bash
sudo cp target/release/rsys /usr/local/bin/
sudo chmod +x /usr/local/bin/rsys
```
